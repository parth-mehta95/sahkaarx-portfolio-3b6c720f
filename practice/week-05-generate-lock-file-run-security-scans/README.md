# Generate Lock File & Run Security Scans

## Task Brief
Create requirements-lock.txt, run pip-audit and safety scans, document vulnerabilities, and finalize production-ready GitHub repo.

## Scenario
Your data science team needs a production-ready package. Generate lock files, scan for vulnerabilities, and publish final repo.

## Deliverables
- requirements-lock.txt with pinned versions
- Security scan reports (pip-audit, safety)

## Success Criteria
- Lock file pins all transitive dependencies
- Security scans run and report findings
