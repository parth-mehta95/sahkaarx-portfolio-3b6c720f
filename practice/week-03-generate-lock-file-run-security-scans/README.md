# Generate Lock File & Run Security Scans

## Task Brief
Create requirements-lock.txt, run pip-audit and safety scans, document vulnerabilities, and finalize production-ready GitHub repo.

## Scenario
Your data utility library needs production-grade dependency management. Generate lock files and run security audits.

## Deliverables
- requirements-lock.txt file
- Security audit report with pip-audit and safety results
- Vulnerability documentation

## Success Criteria
- Lock file pins all transitive dependencies
- Security scan identifies and documents vulnerabilities
- Report includes remediation steps
