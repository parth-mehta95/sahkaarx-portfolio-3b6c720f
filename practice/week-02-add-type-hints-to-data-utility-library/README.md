# Add Type Hints to Data Utility Library

## Task Brief
Extend your GitHub repository by adding type hints to all utility functions and create a typed data model class.

## Scenario
Your team needs type-safe data utilities. Add type annotations to validation functions and build a typed data model.

## Deliverables
- Updated GitHub repo with type hints
- Typed data model class

## Success Criteria
- All functions have complete type annotations
- Data model class uses dataclass or TypedDict
