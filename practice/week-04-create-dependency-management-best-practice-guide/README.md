# Create Dependency Management Best-Practice Guidelines

## Task Brief
Document version pinning strategies, license compliance procedures, and security scanning workflows for your data utility library.

## Scenario
Your data science team needs clear dependency management guidelines. Create a comprehensive best-practices document covering versioning, licensing, and security.

## Deliverables
- Dependency management guidelines document
- Version constraint strategy guide
- License compliance procedures document

## Success Criteria
- Guidelines cover semantic versioning best practices
- License verification workflow is documented
- Security scanning procedures are included
