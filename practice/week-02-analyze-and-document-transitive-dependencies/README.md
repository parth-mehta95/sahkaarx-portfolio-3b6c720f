# Analyze and Document Transitive Dependencies

## Task Brief
Examine your library's transitive dependencies, document the dependency tree, and identify potential conflicts.

## Scenario
Your data utility library depends on multiple packages. Map out transitive dependencies and document the full tree.

## Deliverables
- Dependency tree diagram or text file
- requirements.txt with all transitive deps

## Success Criteria
- All direct and transitive dependencies listed
- Potential version conflicts identified
