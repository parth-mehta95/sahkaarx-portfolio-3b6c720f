# Extend Data Utility Library with Dependency Tree Analysis

## Task Brief
Define initial requirements.txt with direct dependencies; document and visualize the transitive dependency tree for your data utility package.

## Scenario
Your data science team needs a documented dependency map. Add direct dependencies to requirements.txt and create a visual dependency tree.

## Deliverables
- Updated requirements.txt with direct deps
- Dependency tree diagram or text file

## Success Criteria
- All direct dependencies listed with versions
- Transitive deps identified and documented
